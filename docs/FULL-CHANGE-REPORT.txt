MSB PHARMACHEM WEBSITE & BUSINESS PORTAL
FULL CHANGE REPORT (Nov 2026)
===============================================================

Local site:  http://localhost:3000
Admin login: http://localhost:3000/login (single admin account)

---------------------------------------------------------------
PART A: BACKEND (ADMIN PORTAL)
---------------------------------------------------------------

A1. Admin portal reduced to 5 features
    - Menu now: Dashboard, Enquiries & Leads, Goods Receipt (GRN),
      Invoices & Payments, Reports & Exports.
    - Removed: Product Master, Inventory & Batches, Customers, Suppliers,
      Purchase Orders, Quotations, Delivery Challans, Audit Logs,
      System Settings, and their APIs.
    - Products stay fixed in the database, so the public Products page is
      unaffected.

A2. Admin only: no employees
    - Removed the staff logins: sales@, accounts@, inventory@,
      paytharlaa@ and mohank9@. Only admin@msbpharmachem.com remains.
    - Their past records were moved to the admin account.
    - Removed the role / permission system.

A3. Security fixes
    - Removed hard-coded "backdoor" passwords that let anyone into any
      super-admin account.
    - Removed the login page's quick-fill buttons, which showed passwords
      publicly.
    - Every admin API and PDF download now requires the admin login.
      Previously some PDFs and lists were open to anyone.

A4. Dashboard
    - Cards: new enquiries, GRNs this month and pending QC, billed this
      financial year (with GST), outstanding and overdue.
    - 6-month billing chart, receivables summary, and the latest enquiries,
      GRNs and invoices.
    - Global search box that searches enquiries, GRNs and invoices at once.

A5. Enquiries & Leads
    - Search, status filter, Manage Lead panel and notes (as before).
    - NEW: "Assigned to" field in Manage Lead. Type any name and save. The
      name shows in the list and is searchable.
    - NEW: Excel export in register format with an Assigned To column
      (see A9).

A6. Goods Receipt (GRN): matches the supplied GRN & Incoming Inspection
    PDF
    - The form asks every question in the PDF:
        Supplier and document details: PO, invoice, vehicle,
          transporter / LR, e-way bill, received at.
        Material lines: description, batch, Mfg / Exp (retest), qty as
          per invoice, qty received, UOM, no. of containers, accepted /
          rejected qty and remarks.
        10-point inspection checklist: Yes / No / N/A.
        QC: sample ref, sampled by, date, status, storage location,
          temperature, action on rejection.
        Three-way match, remarks / discrepancies.
        Received / Inspected / Verified / Approved by (name and date).
    - The PDF is generated on the same grid as the client template, with
      ticks and values filled in.
    - Search, QC-status filter, edit and delete.
    - Numbering: MSB/GRN/2026-27/NNN.

A7. Invoices & Payments: GST tax invoices
    - Invoice fields follow the Sales Register format:
        Customer, GSTIN, place of supply, category (B2B / B2CL / B2CS /
          Export), invoice type, reverse charge.
        Per line: HSN, UQC, qty, rate, GST rate.
    - GST calculates automatically: CGST + SGST within Telangana, IGST
      for other states.
    - Payments: record, remove, and overpayment is blocked. Status shows
      Unpaid / Partially paid / Paid.
    - Returning customers auto-fill their details. Search and status
      filter. Totals cards (billed / received / outstanding).
    - NEW tax invoice PDF in the client's "TAX INVOICE" template format:
        Letterhead: Phone / Email / Web, GSTIN / PAN / IEC.
        Original / Duplicate / Triplicate line.
        Details grid: invoice no., date, PO, place of supply, payment
          terms, due date, transport / vehicle, e-way bill / LR.
        Billed To (buyer) and Shipped To (consignee), with
          "Same as Billed To".
        Goods table: S.No, description, HSN, Batch No. / Mfg-Exp, qty,
          pack details, UOM, rate per UOM, amount.
        Bank details and amount in words.
        Totals: Total Taxable Value, Less Discount, Freight / Packing,
          CGST, SGST, IGST (always shown), Round Off, GRAND TOTAL.
        Terms & Conditions and signatures (Receiver / Authorised
          Signatory).
    - NEW form fields: payment terms, consignee (shipped to), batch no.,
      Mfg / Exp dates, pack details, invoice-level discount and
      freight / packing, round-off.
    - NEW editable Terms & Conditions on every invoice, pre-filled from the
      template terms (blanks set to 7 days / 18%).
    - NEW "Invoice Settings" button: company email, website, GSTIN, PAN,
      IEC, bank details and default terms. Blank values print as "____"
      lines.
    - NEW numbering: MSB/D/26-27/NNN (15 characters, within GST's limit).
      It continues from the last invoice, so the next is MSB/D/26-27/013.
      Restarts at 001 each new financial year. Older invoices keep their
      numbers.

A8. GST Sales Register (Excel)
    - Downloads the client's own "Sales Register Format (MSB).xlsx",
      filled with one row per product per invoice.
    - Same colours, dropdowns, formulas, frozen panes, hidden helper
      columns and Row Check. The broken external "Setup" link was fixed.
    - Verified identical to the template's example rows.

A9. Reports & Exports
    - Reports:
        GST Sales Register.
        Leads Register (with Assigned To, business type, target standard,
          follow-ups).
        GRN Register, Payments Received, Outstanding Receivables.
    - Every report has a date range, search and on-screen preview.
    - Excel downloads now all use the Sales Register style: blue title
      bar, summary row, blue header, grid lines, frozen headers, filters,
      print-ready.
    - CSV is still available.
